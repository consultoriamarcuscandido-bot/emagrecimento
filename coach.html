Configuração do Supabase

1

Crie um projeto no Supabase

Acesse supabase.com → "Start for free" → crie um projeto chamado emagrecimento. Plano gratuito suporta até 500MB e requisições ilimitadas.

2

Execute o SQL para criar as tabelas

No Supabase → SQL Editor → cole e execute:

create table if not exists alunos ( id uuid default gen_random_uuid() primary key, nome text not null, email text, whatsapp text, peso_inicial numeric, objetivo text, semana_inicio date default current_date, ativo boolean default true, criado_em timestamptz default now() ); create table if not exists checkins ( id uuid default gen_random_uuid() primary key, aluno_id uuid references alunos(id) on delete cascade, semana int not null, dia int not null, checks jsonb default '{}'::jsonb, nota text, criado_em timestamptz default now(), unique(aluno_id, semana, dia) ); create table if not exists monitoramento ( id uuid default gen_random_uuid() primary key, aluno_id uuid references alunos(id) on delete cascade, semana int not null, peso numeric, cintura numeric, humor text, energia text, controle_fome text, treinos_semana int, fotos_enviadas boolean default false, obs text, criado_em timestamptz default now(), unique(aluno_id, semana) ); -- Permissões anon (necessário para o app do aluno funcionar sem login) alter table alunos enable row level security; alter table checkins enable row level security; alter table monitoramento enable row level security; create policy "alunos_read" on alunos for select using (true); create policy "alunos_insert" on alunos for insert with check (true); create policy "checkins_all" on checkins for all using (true) with check (true); create policy "monitoramento_all" on monitoramento for all using (true) with check (true);
3

Cole suas credenciais

Supabase → Settings → API

4

Hospede no Vercel (grátis)

1. Crie uma conta em vercel.com
2. Crie um repositório no GitHub com os 2 arquivos (coach.html e aluno.html)
3. Importe o repositório no Vercel → deploy automático
4. O link do aluno será: seuapp.vercel.app/aluno.html?id=ID_DO_ALUNO
